# Tech Stack Animation Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a one-shot-per-load GSAP + ScrollTrigger intro to the Tech Stack section, with header-first sequencing and a grid-aware card reveal that scales with card count changes.

**Architecture:** Keep `StackSection.astro` and `SkillChip.astro` as the existing rendering foundation, then add a dedicated stack animation runtime under `src/lib/animations/stack/`. Follow the same pattern already established for About: add explicit `data-*` hooks in the section markup, create a controller that owns the timeline, and create an initializer that owns `ScrollTrigger`, reduced-motion behavior, and cleanup.

**Tech Stack:** Astro, GSAP, ScrollTrigger, Vitest, global CSS

---

## Runtime Contract To Implement

### Required Hooks
- `data-stack-root`
- `data-stack-header`
- `data-stack-eyebrow`
- `data-stack-title`
- `data-stack-grid`
- `data-stack-card`

### Required Behavior
- One animation per page load
- Replay only after reload
- Header first, cards second
- Cards animated as units
- Dynamic selection of cards, no hardcoded card count
- Reduced-motion path with minimal choreography
- Responsive behavior aligned with existing `stack.css` breakpoints (`64rem` and `48rem`)
